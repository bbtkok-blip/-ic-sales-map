【公開方法】
1. GitHubにログイン
2. 新しいRepositoryを作成
3. この3ファイルをアップロード
4. Repositoryの Settings → Pages
5. Branch を main / root にして Save
6. 数分後に表示される https://ユーザー名.github.io/リポジトリ名/ をSafariで開く

【iPhoneでアプリ風に使う】
Safariで公開URLを開く
→ 共有ボタン
→ 「ホーム画面に追加」
